# GoRun Cambodia 🇰🇭

A web discovery platform connecting runners, students, young adults, and beginners with running events, charity races, and marathons across Cambodia.

## 👥 Team Members
- GoRun Cambodia Class Project Team

## 🎯 What It Does
- **Bilingual Discovery**: Switch instantly between Khmer (ភាសាខ្មែរ) and English.
- **Event Search & Filter**: Search events by keyword, cause/category (Charity, Awareness, Marathon, Fun Run), distance (3km to 42km), and province.
- **Event Details & Fees**: Clear breakdown of dates, routes, registration deadlines, and pricing in both USD ($) and Cambodian Riel (៛).
- **Official Registration Links**: Direct access to organizer sign-up pages.
